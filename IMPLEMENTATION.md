# Итоговая структура проекта «Очаг»

## Созданные файлы

### 📁 src/types/
- `index.ts` - TypeScript типы (User, Chat, Message, Poll, Attachment, Contact, Location)

### 📁 src/api/
- `client.ts` - Axios клиент с настроенными interceptors для авторизации

### 📁 src/components/ui/
- `Avatar.tsx` - Компонент аватара с поддержкой border и размеров
- `Button.tsx` - Кнопка с вариантами (primary, secondary, outline, ghost)
- `Input.tsx` - Текстовое поле с лейблом и валидацией
- `Toggle.tsx` - Переключатель on/off
- `Badge.tsx` - Значки с цветовыми вариантами
- `Card.tsx` - Карточка контента
- `index.ts` - Экспорт всех UI компонентов

### 📁 src/pages/
- `LoginPage.tsx` - Экран входа с телефоном и SMS кодом
- `ChatsPage.tsx` - Список диалогов и кооперативов
- `ChatPage.tsx` - Экран чата с сообщениями, закрепленными и упоминаниями
- `ProfilePage.tsx` - Профиль пользователя с настройками
- `SearchPage.tsx` - Поиск по всему контенту
- `VoiceCallPage.tsx` - Экран голосового звонка с визуализацией
- `AttachmentsPage.tsx` - Вложения: опросы, локации, контакты, фото

### 📁 src/
- `App.tsx` - Главный компонент с роутингом (React Router)
- `main.tsx` - Точка входа приложения
- `index.css` - Глобальные стили

### 📁 Конфигурация
- `vite.config.js` - Настройки Vite с алиасами
- `.env` - Переменные окружения (API_URL)
- `README.md` - Документация проекта

## Ключевые особенности реализации

✅ **Pixel-perfect дизайн** - точное соответствие макетам с темной темой (#0A0A0A) и розовым акцентом (#E91E63)

✅ **TypeScript** - строгая типизация всех данных, props и state

✅ **Модульная архитектура** - переиспользуемые UI компоненты, отделенные от бизнес-логики

✅ **React Router** - навигация между 7 основными экранами

✅ **API Integration** - готовый Axios клиент с interceptors для работы с backend

✅ **Responsive** - адаптивная верстка под мобильные устройства

✅ **Анимации** - плавные переходы, пульсирующие кольца на звонке, волновая визуализация

## Дизайн-система

**Цветовая палитра:**
- Основной фон: #0A0A0A
- Карточки: #1A1A1A
- Акцент: #E91E63
- Границы: #2A2A2A
- Текст: #FFFFFF / #999999 / #666666

**Радиусы:**
- Кнопки/инпуты: 12-24px
- Карточки: 16px
- Аватары: circle

**Типографика:**
- Система: -apple-system, Segoe UI, system-ui
- Размеры: 12-32px
- Жирность: 400-700
